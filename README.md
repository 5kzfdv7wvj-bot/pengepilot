# PengePilot – AI-økonomi prototype

Klikbar, statisk HTML-prototype til en personlig AI-økonomiapp. Alle data er placeholder-data.

## Sider

- Overblik
- Importér bankudtog
- Transaktioner og AI-kategorisering
- Budget
- Abonnementer
- Regninger
- Penge fundet
- Mål & simulator
- AI-assistent
- Sundhedsscore
- Prognose
- Konti
- Rapporter
- Indstillinger

## Kør lokalt

Projektet kræver ingen build-proces. Åbn `index.html` direkte i browseren, eller start en simpel statisk webserver.

## GitHub Pages

Repoet indeholder `.github/workflows/pages.yml`, som er klar til deployment via GitHub Pages / GitHub Actions fra `main`.

Efter første push: gå til **Settings → Pages → Build and deployment → Source: GitHub Actions**, hvis GitHub ikke allerede har aktiveret workflow-deployment automatisk.

## Bemærkning

Denne prototype uploader ikke bankdata til nogen server. Filimporten er kun en visuel demo og simulerer analyse i browseren.
